# Apex 灵敏度实验室

面向 Apex Legends 玩家的纯前端单文件网页工具。通过标准化五维瞄准测试，帮助玩家快速自测并找到适配自身操作习惯的鼠标灵敏度，配套参数换算、全维度配置优化、跨游戏灵敏度转换等能力。

## 特性

- **纯本地运行** — 所有计算和数据存储均在浏览器端完成，无后端服务，不上传任何用户数据
- **开箱即用** — 单 HTML 文件，双击直接打开使用，无需安装部署
- **闭环体验** — 自测 → 出方案 → 参数优化 → 工具辅助，一站式完成调参

## 功能模块

### 1. 五维灵敏度自测
使用 Canvas + Pointer Lock API 实现交互式瞄准测试：
- 转身校准 — 模拟游戏灵敏度完成 360° 旋转
- 跟枪测试 — 追踪匀速/变速/不规则三种运动模式的移动靶标
- 急停定位 — 随机位置 10 个靶标依次点击
- 多目标转移 — 按序命中 3 个靶标 × 5 轮
- 压枪测试 — 补偿后坐力保持准星在目标区域

### 2. 智能参数推荐
根据测试结果分析灵敏度偏高/偏低/均衡，生成三套方案（保守/均衡/激进），自动换算 eDPI、cm/360，支持 FOV 变化时手感统一换算。

### 3. 全套游戏参数优化
鼠标、画面画质、准星（含实时预览）、音效、按键布局五个维度，排位/练枪双模式切换，支持 JSON 配置导入导出。

### 4. 实用工具集
- 跨游戏灵敏度转换器（Apex / CS2 / Valorant / OW2 / R6 / CoD / PUBG / The Finals）
- 职业选手参数库（10 位 ALGS 选手，支持一键套用）
- 瞄准练习方案（5min 热身 / 20min 日常 / 10min 赛前）

## 使用方法

直接用浏览器打开 `index.html` 即可使用，推荐 Chrome 90+ 或 Edge 90+。

## 技术栈

- HTML + CSS + Vanilla JavaScript（原生 JS，不使用框架）
- Tailwind CSS (CDN) — 页面样式
- Chart.js (CDN) — 雷达图与数据可视化
- Canvas API + Pointer Lock API — 瞄准测试场景
- localStorage — 本地数据存储
